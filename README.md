# 圖面工坊

既有圖面（點陣掃描檔）的尺寸改圖工具。原圖不被改寫，圖形不隨尺寸變形——
以白底遮罩蓋住原尺寸文字，再依尺寸表疊上新的數值與公差，輸出標示「不依比例，尺寸以標註為準」的試作圖。

## 執行

```bash
python3 -m http.server 8000
# 瀏覽器開啟 http://localhost:8000
```

請用本機伺服器開啟，不要直接以 `file://` 點兩下開啟：瀏覽器會封鎖畫布讀取，導致
PNG 輸出與列印失效。

## 目前內容

`assets/` 內為 5 張底圖（1414×2000 JPG），分兩個類型群組：

| 類型群組 | 圖面 | 可填尺寸 |
|---|---|---|
| 錐尖頂針 P | D4P001000001、B4P001000001、C4P001000002 | 各 13 個 |
| 球頂／異型 J | C4J002000001、D4J013000001 | 尚未設定，原圖可查看 |

三張錐尖頂針的欄位為：凸緣外徑、中段軸徑、導柱徑、中心孔徑、尖端內圓角、
段高 H1–H5、總長、頸縮徑、底徑。遮罩座標以原圖像素量測後校準。

## 換成自己的圖組

1. 把 JPG 放進 `assets/`。
2. 編輯 `index.html` 最上方的 `SEED` 陣列：每張圖一筆，填入 `asset.src` / `asset.w` / `asset.h`、
   `typeGroup`、`info`（圖號、材質）、`frameRegion`（要蓋掉的舊圖框區域）。
3. `fields` 可留空，改在畫面上用「設定範本 → 框選新尺寸」逐一建立。

座標一律以原圖像素為準，與畫面縮放無關。

## 資料層

| 層 | 內容 | 更新時機 |
|---|---|---|
| 範本主檔 templates | 底圖引用、欄位、遮罩、預設值、版本號 | 按「保存範本新版」 |
| 工作草稿 drafts | 自己持有的範本副本、實際尺寸、公差、圖面資訊 | 編輯後自動保存（去抖動 300ms） |
| 已存圖面 saved | 完整草稿快照 | 每按一次「另存圖面」新增一筆 |
| 畫面狀態 ui | 目前範本、模式、選取、分類、縮放 | 操作過程更新 |

快照內含範本副本，所以日後修改範本不會改寫舊圖面。

保存於瀏覽器 IndexedDB，依瀏覽器與網址來源隔離（不同瀏覽器、localhost 與 127.0.0.1、
不同連接埠都不共用）。清除網站資料會移除紀錄，沒有伺服器備份或多人同步。
換電腦請用「備份資料」匯出 JSON 並保留整個專案資料夾——備份不含底圖 JPG。

復原保留最多 60 個檢查點，重整頁面後消失，沒有重做。

## 尚未實作

自動 OCR、任意圖片上傳、幾何變形、尺寸公式與跨欄位連動、工程合理性檢查、
圖號配發、BOM／ERP 串接、權限、正式審核與變更紀錄、多人共用與版本歷史。

必填檢查只確認欄位非空白，不代表設計檢核通過。系統不驗證數值是否合理、
公差上下限是否顛倒、孔徑是否小於外徑。
